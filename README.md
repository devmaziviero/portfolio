# Portfólio · Enzo Maziviero

Portfólio pessoal de Enzo Maziviero, Analista de Sistemas e Desenvolvedor Full Stack.

Página única em **HTML, CSS e JavaScript puros**, sem framework e sem etapa de build. As figuras em pixels e os gráficos são gerados por código a partir dos dados da trajetória.

## Estrutura

```
index.html   página inteira (estilos e scripts embutidos)
assets/      foto, avatar e miniaturas dos projetos
```

## Rodar localmente

```bash
npx http-server . -p 5180 -c-1
```

Abra http://localhost:5180

## Deploy

Hospedado na Vercel. Cada push na branch `main` publica automaticamente.
